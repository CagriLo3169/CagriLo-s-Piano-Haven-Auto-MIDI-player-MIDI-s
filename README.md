## 🎵 About The Repository

This repository contains a curated library of MIDI arrangements optimized for performance, sound limits, and note restrictions within Roblox piano games. The collection includes popular memes, game soundtracks (Undertale, Honkai: Star Rail), classic pieces, and extreme "Rush E" style arrangements.

### Key Features
* **Roblox Optimized:** Specially tweaked, nerfed, or buffed note densities to avoid lag and game kicks.
* **Arts & Non-Arts Variants:** Separate arrangements tailored for visuals (piano key art) and sound clarity.
* **Variety of Styles:** Black MIDI, Extreme/Nuker challenges, Meme tracks, and classical remixes.

## 🚀 How to Use

1. **Download the MIDI:**
   * Browse the repository list above and select the `.mid` file you want.
   * Click **Download raw file** to get install the MIDI file. Piano haven will ask for an raw download link so just go to downloaded files, copy the download link.

2. **Load into Player:**
   * Import the download link into your auto Roblox piano haven auto player.
   * Adjust your player's delay/BPM settings if the piece features high note counts.

## ⚡ Performance Note

* Files marked with **`boblox`** or **`nerfed`** are safe for Roblox game performance and server stability.
* Files marked with **`ARTS`**, **`RIP PC`**, or **`Nuker`** contain loud noises.
